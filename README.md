## 🚧 What I'm Building

I own the end-to-end data platform at Unimed — from legacy source systems to analytics-ready models.

```
Oracle · SQL Server · MySQL · Google Sheets
              │
              ▼
   Custom ingestion framework (Python · pyarrow · incremental watermarks)
              │
              ▼
   Snowflake  ──  BRONZE (raw)  →  SILVER (staging)  →  GOLD (star schema)
              │              dbt orchestrated by Airflow 3 + Astronomer Cosmos
              ▼
   Power BI dashboards · Streamlit observability · Snowflake Cortex AI
```

- **Orchestration** — Apache Airflow 3 (CeleryExecutor) on Docker Compose / EC2, dbt models as Airflow tasks via Cosmos
- **Modeling** — 100+ dbt models (Silver staging with dedup/typing, Gold dimensions & facts)
- **Ingestion** — replaced Airbyte with a lightweight Python framework (~200 MB RAM per chunk, incremental via watermarks)
- **Governance** — Snowflake RBAC, tag-based masking policies for LGPD compliance, audit views
- **Ops** — secrets in AWS SSM Parameter Store, CI/CD with GitHub Actions (`dbt parse` + `sqlfluff` on PRs, automated deploy), failure alerts to Microsoft Teams, FinOps cost tracking
